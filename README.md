# TransKey

### العربية
**TransKey** هي أداة برمجية خفيفة مفتوحة المصدر لنظام ويندوز، مصممة لتحويل تجربة الكتابة والترجمة. تسمح لك الأداة بكتابة النص بأي لغة ثم الضغط على زر `Enter` ليتم استبدال النص فوراً باللغة المترجمة داخل أي تطبيق تستخدمه (مثل واتساب، ديسكورد، أو محررات النصوص)، دون الحاجة لنسخ ولصق يدوي أو فتح متصفح.

**المميزات الرئيسية:**
- **ترجمة فورية:** استبدال مباشر للنص داخل أي خانة إدخال.
- **خفيفة وسريعة:** ملف تنفيذي واحد لا يحتاج لتثبيت.
- **خصوصية عالية:** بدون إعلانات أو تتبع.
- **دعم لغات متعدد:** يدعم مجموعة واسعة من اللغات العالمية.

### English
**TransKey** is a lightweight, open-source utility for Windows designed to revolutionize your typing and translation experience. It allows you to type in your native language, press `Enter`, and have the text instantly replaced with its translation within any application (chat apps, games, document editors, etc.) without manual copy-pasting or switching windows.

**Key Features:**
- **Real-Time Translation:** Direct text replacement in any input field.
- **Lightweight & Portable:** Single executable file; no installation required.
- **Privacy-Focused:** No ads, no tracking, and no hidden data collection.
- **Wide Language Support:** Supports a vast range of global languages.

### 中文 (Chinese)
**TransKey** 是一款轻量级的开源 Windows 工具，旨在彻底改变您的打字和翻译体验。它允许您输入母语，按下 `Enter` 键，即可在任何应用程序（聊天软件、游戏、文档编辑器等）中将文本即时替换为翻译后的内容，无需手动复制粘贴或切换窗口。

**主要功能：**
- **实时翻译：** 在任何输入框内直接进行文本替换。
- **轻量便携：** 单个可执行文件，无需安装。
- **隐私保护：** 无广告、无跟踪、无隐藏数据收集。
- **语言支持：** 支持多种全球语言。

### Русский (Russian)
**TransKey** — это легкая утилита с открытым исходным кодом для Windows, созданная для того, чтобы изменить ваш опыт ввода текста и перевода. Она позволяет вам вводить текст на родном языке, нажать `Enter` и мгновенно заменить его переводом в любом приложении (чаты, игры, редакторы документов и т.д.) без необходимости копирования, вставки или переключения окон.

**Основные возможности:**
- **Мгновенный перевод:** Прямая замена текста в любом поле ввода.
- **Легкость и портативность:** Один исполняемый файл, не требует установки.
- **Конфиденциальность:** Без рекламы, без отслеживания, без скрытого сбора данных.
- **Поддержка языков:** Поддержка широкого спектра мировых языков.
